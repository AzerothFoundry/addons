# 原版天赋预览

面向WoW 1.12，使用`/tpv`或天赋快捷键打开，支持预览、复制当前与确认后应用。预览和悬停不学习天赋，只有确认应用才会消耗真实点数。

需要从自己的游戏数据生成本地TalentData.lua；源码仓库仅保留空占位。安装和升级保留现有TalentData.lua与SavedVariables，不用源码占位表覆盖已安装数据。

0.1.1修复首次打开时悬停访问未初始化预览表的问题：先复制实际天赋再构建面板，构建期间隐藏窗口，并容忍提示回调暂时缺少预览分系。实际Lua模块回归见`tests/verify_talent_preview.lua`，覆盖首次悬停、不同节点、重开和不学习天赋；这不代替真实客户端验收。

跨仓库计划和验收记录统一在工作区wow-gm-control/docs维护，关联ISSUE-0063。

0.1.2进一步修复旧Lua闭包捕获：悬停回调必须引用循环体内单独保存的天赋节点，不能捕获循环变量node；旧Lua中循环结束后该变量可变为nil。0.1.1的预览表防护未覆盖此原因。`python3 tests/run_talent_vm.py`使用benilla-lua的客户端Lua语义运行真实模块fixture，覆盖清空预览后悬停、不同节点、100点预算与不学习天赋；普通Lua5.4通过不能代替这项验证。
