# EzDismount目标保护

适配1.12的EzDismount2.03，作为独立插件加载，未复制或修改第三方源码。安装时必须同时保留EzDismount，依赖加载顺序由TOC指定。

保守拦截骑乘错误引起的自动下马：没有选中目标、死亡目标或既不能攻击也不能协助的目标时保留骑乘。仍使用EzDismount处理其余行为，手动下马、出租坐骑和拍卖行独立入口不改变。

此模式也会阻止无目标自身法术和采集错误触发自动下马，需要手动下马。它只修复目标保护，不保证法术对一个存活目标适用，不保证视线/射程/朝向或一次按键完成施法；不能把骑乘错误视为其他条件全部通过。

关联工作区计划中心ISSUE-0064；实际游戏行为待用户重新启动客户端验证。
